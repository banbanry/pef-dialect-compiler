# 02 · 道家方言编译报告

> 方言领域：道家（《道德经》核心断言）
> 编译目标：把「道可道」「无为」「反者道之动」拆回 `P + ΔV → J`，标锚，记勘误
> 编译方法：见 `docs/method.md`；语法见 `docs/grammar.md`

---

## 编译对象 1：道可道，非常道

**方言原句**：「道可道，非常道。」（《道德经》第一章）

拆解：

```
P:   说者（带时间戳：某个此刻的言说行为）
ΔV:  可道之道（被语言投影的内容；从产生岸看是内容，
      从接收岸看是势能差）
J:   被说出的「道」（落地为一句可被接收侧核验的断言）
────────────────────────────
锚:
  硬锚:    无（「常道」不可测量、不可复现）
  押金类比: 「可道」= 一次有损投影；「非常道」= 投影不是源
  软锚:    「常道」——只存在于说话者的指认中
证据层:    框架内事实（本编译器的语言哲学假定）
勘误:      （无，本节为首次编译）
────────────────────────────
```

**编译说明**：

这句是「源的三条禁令」的最早版本。拆开看：「可道」是 P 的一次言说，产出 J；「非常道」说 J 不是源。用 PEF 讲：**道是 P 的投影，不是 P 本身；凡被说出的都是 J，J 永远不是 ΔV 的源头。**

注意这节的锚全是软的——「常道」没有硬锚。所以这节只能作为**框架内事实**存在，不能当作对宇宙的断言。它指示方向（源不可命名），不给出内容（源是什么）。

## 编译对象 2：无为而无不为

**方言原句**：「无为而无不为。」（《道德经》第三十七章）

拆解：

```
P:   主体（带时间戳：处于某个状态中的行事者）
ΔV:  势能差（环境给出的、可被借用的力）
J:   事成（落地为可观察的结果）
────────────────────────────
锚:
  硬锚:    无（「事成」不可形式化测量）
  押金类比: 摆渡人七天——不硬顶急流、借势转向；
           死湾等风（无势能差不强推）
  软锚:    无
证据层:    框架内事实（与《摆渡人的七天》同构）
勘误:      #1 见下
────────────────────────────
```

**勘误 #1：「无为」不是不动**

原断言（常见误读）：无为 = 什么都不做。

判定：把「不干预」当成了「不动作」。「无为」若等于不动，就退化成被动漂移——放弃边界，被环境熵溶解，撞礁。

修正：无为 = **不主动制造势能差，只在势能差存在时借力**。摆渡人的「死湾等风」是无为（不推船），风暴中调帆也是无为（借风力不顶风力）。差别不在动不动，在**谁提供 ΔV**：自己硬造 ΔV 是「有为」，借环境已有 ΔV 是「无为」。

这条编译和《摆渡人的七天》的「动态稳态」同构：不是不动，是每刻都在调，且每次调整都只顺着势能差走。

## 编译对象 3：反者道之动

**方言原句**：「反者道之动，弱者道之用。」（《道德经》第四十章）

拆解：

```
P:   道（无时间戳——标记 P?）
ΔV:  （过手的是什么？未指明）
J:   （落在哪一侧？未指明）
────────────────────────────
锚:
  硬锚:    无
  押金类比: 「反」= 反馈/回归；「弱」= 不顶、借力
  软锚:    「道」作为动作者
证据层:    框架内事实
勘误:      #2 见下
────────────────────────────
```

**勘误 #2：「反者道之动」的主语不是主体，是回路**

原断言（表面读法）：道在运动，运动方式是返回。

判定：把「道」当成了有意志的动作者（P?）。「反者道之动」里，真正在动的是**变量**：物极必反、盛极而衰、周行不殆——这是变量层的回归，不是主体层的行动。

修正：**「反」是审计链的性质，不是主体的性质。** 闭环系统里，变量必须回归（锚定、回到可测量基线），否则系统发散。道德经把它说成「道之动」，PEF 把它说成「锚定与审计的必要性」——同一件事，两种方言。

「弱者道之用」同理：弱 = 不顶 = 借力，与「无为」同构。

## 编译对象 4（反例演示）：上善若水

**方言原句**：「上善若水。水善利万物而不争。」（《道德经》第八章）

拆解：

```
P:   善者（带时间戳：处于具体处境中的行事者）
ΔV:  处境给出的势能差（水的流向）
J:   利万物（落地为可观察的结果）
────────────────────────────
锚:
  硬锚:    无
  押金类比: 水=动态稳态的模范：遇弯借势、遇石绕行、
           不硬顶、但持续向前
  软锚:    「善」作为实体属性
证据层:    框架内事实
勘误:      #3 见下
────────────────────────────
```

**勘误 #3：水不是不争，是换了个战场**

原断言（常见误读）：水柔弱，所以不抵抗。

判定：把「不争」理解成「不行动」。「水善利万物而不争」若拆成 PEF：水的 J 是「利万物」——这本身就是巨大的结果，只是它不通过硬顶产生。

修正：**水的不争是借力方式的描述，不是结果的缺席。** 它绕石是 J 的路径选择，不是 J 的放弃。同理，无为不是不为，是换一种方式为。方言把「不硬顶」翻译成「不争」，翻译有损——丢了「J 依然落地」这半句。

---

## 本篇勘误卡

| # | 原断言 | 判定 | 修正 |
|---|---|---|---|
| 1 | 无为 = 什么都不做 | 退化成被动漂移 | 不主动造 ΔV，只在势能差存在时借力 |
| 2 | 道在运动，方式是返回 | 把变量层回归当成主体行动 | 「反」是审计链的性质（变量必须回到基线） |
| 3 | 水不争 = 不行动 | 把借力方式当成结果缺席 | 不争是路径选择，J 依然落地 |

## 本篇出处卡

1. 「道可道，非常道」：《道德经》第一章。本编译读作「J 不是源」的方言版本。
2. 「无为而无不为」：《道德经》第三十七章。本编译与《摆渡人的七天》的「动态稳态」同构，为框架内映射，非道家学术定论。
3. 「反者道之动」：《道德经》第四十章。本编译读作「变量必须回归（锚定）」的方言版本，为框架内映射。
4. 「上善若水」：《道德经》第八章。同上。
5. 所有「框架内事实」标注：本节编译是 PEF 对道家文本的映射，不是道家研究的学术结论。原文存在多版本与多诠释，本编译只取与 PEF 结构同构的读法，不声称唯一正确。

---

## 本篇死亡条款

当以下情况发生，本篇失效：

- 出现可独立复现的证据，证明「常道」可被测量（推翻「源不可命名」的框架内假设）；
- 道家文本存在权威诠释，证明「无为」确为「不行动」且系统仍保持稳态（推翻勘误 #1 的修正——这需要给出一个无 ΔV 输入仍稳态的物理系统）。

检验不到，本篇就是一份可反驳的方言映射草稿；检验到了，本篇进勘误，不撤稿。
