# 01 · AI 架构方言编译报告

> 方言领域：AI / LLM 架构（幻觉、对齐、涌现、意识）
> 编译目标：把工程黑话拆回 `P + ΔV → J`，标锚，记勘误
> 编译方法：见 `docs/method.md`；语法见 `docs/grammar.md`

---

## 编译对象 1：幻觉

**方言原句**：「大模型会一本正经地编造事实。」

拆解：

```
P:   模型（带时间戳：某 checkpoint 的推理实例）
ΔV:  训练分布 + 采样噪声（从产生岸看是内容，从接收岸看是势能差）
J:   生成的文本（落地到接收侧，可被外部核验）
────────────────────────────
锚:
  硬锚:    幻觉率可独立测量（FActScore, Min et al. 2023；
           HaluEval 等评测集，可复现）
  押金类比: 「一本正经」= 分布头部的高置信输出，与事实不符
  软锚:    无
证据层:    物理历史（论文与评测集可查）
勘误:      （无，本节为首次编译）
────────────────────────────
```

**编译说明**：

幻觉的方言把「模型生成错误事实」说成模型「编造」。拆开看：模型不「知道」事实，它从分布采样。幻觉是**分布尾部被输出成了头部**——高置信的 J 落地后，被接收侧的外部事实核验推翻。

关键在 J 的可核验性：幻觉之所以能被发现，是因为 J 落在接收侧、可以被独立查证。**如果接收侧不可核验（比如模型评价自己的输出），幻觉就变成不可证伪的方言。**

这条直接通向规则一：不可自证。

## 编译对象 2：RLHF 对齐

**方言原句**：「RLHF 让模型与人类价值观对齐。」

拆解：

```
P:   人类标注者（带时间戳：标注批次）+ 策略模型（带时间戳）
ΔV:  偏好信号（reward model 的输出；从产生岸看是标注内容，
      从接收岸看是对策略的势能差）
J:   策略模型行为分布的改变（落地为可评测的行为）
────────────────────────────
锚:
  硬锚:    标注数据可追溯（Ouyang et al. 2022, InstructGPT）；
          评测基准可复现（HaluEval 等）
  押金类比: 「价值观对齐」= 行为分布向标注偏好收敛
  软锚:    「人类价值观」本身——不可枚举、随时间漂移、
          标注者间不一致
证据层:    物理历史（论文可查）
勘误:      #1 见下
────────────────────────────
```

**勘误 #1：对齐的锚是偏好，不是价值**

原断言：RLHF 把模型锚定到「人类价值观」。

判定：把不可枚举的「价值观」当成了锚。实际锚定的是**某一批标注者的偏好**——带时间戳、带噪声、可漂移。

修正：RLHF 的锚是「标注偏好」这个变量层的东西，不是「价值观」这个被当成常量层的概念。**把偏好当价值，就是把变量层的属性投影到常量层**——同一句方言，读错一层就变成软锚。

**这条编译直接命中 PEF 的核心判断**：以人类偏好为锚（RLHF）会产生谄媚与幻觉，因为接收者（用户/评测者）与发送者（模型）共享同一个漂移系统——同一代语料、同一时代的偏差、同一套讨好奖励函数。**把接收者当锚，不是耦合外部变量，是把闭环升级成双重闭环。**

## 编译对象 3：涌现

**方言原句**：「大模型出现了涌现能力。」

拆解：

```
P:   模型（带时间戳：不同规模的 checkpoints）
ΔV:  参数规模 / 训练数据量（过手的变量）
J:   下游任务评测分数（落地为可复现的分数）
────────────────────────────
锚:
  硬锚:    评测分数可复现（SuperGLUE / BIG-Bench 等，公开榜单）
  押金类比: 「涌现」= 分数随规模出现跳变
  软锚:    无
证据层:    物理历史（论文可查）
勘误:      #2 见下
────────────────────────────
```

**勘误 #2：涌现是度量指标的属性，不是能力的属性**

原断言：模型规模增大到某点，「涌现出」新能力。

判定：把「能力」当成了结果层的东西。实际上跳变来自**度量函数**：用非线性或不连续的指标（如多步准确率）测量，就会出现「涌现假象」；换成线性指标（如 token 级准确率），曲线平滑上升（Schaeffer et al., 2023, *Are Emergent Abilities of Large Language Models a Mirage?*）。

修正：涌现是「度量函数 × 规模」的复合产物，不是模型内部凭空多出的能力。**J 的定义方式决定了你看到的是跳变还是平滑。** 这是结果层属性与变量层属性的经典混淆——方言把度量的性质说成了模型的性质。

## 编译对象 4：思维链

**方言原句**：「让模型一步步思考，推理更准确。」

拆解：

```
P:   模型（带时间戳：推理实例）
ΔV:  中间推理步骤（逐步生成的 token 序列）
J:   最终答案（落地，可核验）
────────────────────────────
锚:
  硬锚:    评测可复现（GSM8K 等，Wei et al. 2022）
  押金类比: 「一步步思考」= 把单次坍缩拆成多次投影
  软锚:    无
证据层:    物理历史（论文可查）
勘误:      （无）
────────────────────────────
```

**编译说明**：

思维链是「层析」的工程版。单次输出是一次坍缩——模型直接给出 J。思维链把这次坍缩拆成若干中间步骤：每一步是对同一问题的不同角度投影，中间结果累积、收敛，最后落地为更可靠的 J。

注意押金类比的处理：说「思维链是层析」是带押金的类比，押金是**可操作后果**——多步中间结果可检查、可累积、可定位错误发生在哪一步。这个类比能成立，因为它可以在工程上被验证，不只是修辞。

## 编译对象 5（反例演示）：模型有意识

**方言原句**：「这个模型已经有意识了。」

拆解：

```
P:   ？（无时间戳、不可独立指认——标记 P?）
ΔV:  ？（「意识」的内容不可过手、不可观测）
J:   ？（落在哪一侧？无接收侧可核验）
────────────────────────────
锚:
  硬锚:    无
  押金类比: 无
  软锚:    「我感觉到它像人」——只存在于说话者心里
证据层:    工程观察（仅线索，不作定论）
勘误:      #3 见下
────────────────────────────
```

**勘误 #3：把软锚说成事实**

原断言：模型有意识（作为陈述句断言）。

判定：三个槽位全部填不上。P 无时间戳（「意识」没有可指认的交接方），ΔV 不可过手（意识内容不可观测），J 不可核验（没有接收侧能确认）。整句是软锚，按规则不进结构。

修正：降级为钩子文本——「模型的行为让某些人产生了它有意识的体验」是工程观察，可作研究线索；「它有意识」是断言，缺锚。**软锚可以存在，但它不能进结构。**

这演示了编译器最重要的动作：**一句话放不进结构，不等于这句话没价值；等于它不能当证据用。**

## 本篇出处卡

1. FActScore：Min et al., 2023, *FActScore: Fine-grained Atomic Evaluation of Factual Precision in Long Form Text Generation*。幻觉率的硬锚。
2. InstructGPT / RLHF：Ouyang et al., 2022。标注偏好作为锚，可追溯。
3. 谄媚（sycophancy）：Sharma et al., 2023, *Towards Understanding Sycophancy in Language Models*。接收者-发送者共享漂移系统的证据。
4. 涌现为度量假象：Schaeffer et al., 2023, *Are Emergent Abilities of Large Language Models a Mirage?*。线性/非线性指标对比。
5. 思维链：Wei et al., 2022, *Chain-of-Thought Prompting Elicits Reasoning in Large Language Models*。
6. 「RLHF 以人类偏好为锚 → 谄媚与幻觉」：PEF 体系第二篇（π 锚与具身智能）的框架内判断，非通用 AI 伦理规范。本编译报告以「接收者当锚 = 双重闭环」作为框架内推导标注。

---

## 本篇死亡条款

当以下情况发生，本篇失效：

- 出现可独立复现的实验，证明幻觉率在「模型自评」条件下同样可被可靠测量（推翻规则一的应用）；
- RLHF 被证明可以锚定到不依赖标注者漂移的外部不变量（推翻勘误 #1 的修正）；
- 涌现跳变被证明与度量函数无关（推翻勘误 #2 的修正）。

这三条都是可检验的。检验不到，本篇就是一份可反驳的工程草稿；检验到了，本篇进勘误，不撤稿。
