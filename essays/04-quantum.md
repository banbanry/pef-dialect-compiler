# 04 · 量子力学方言编译报告

> 方言领域：量子力学（叠加态、测量、贝尔不等式、π）
> 编译目标：把量子力学的核心断言拆回 `P + ΔV → J`，标锚，记勘误
> 编译方法：见 `docs/method.md`；语法见 `docs/grammar.md`
> 前置：本卷压轴篇。量子方言是四篇中**锚最硬**的——它的一整套结论都有实验背书。

---

## 编译对象 1：叠加态

**方言原句**：「一个粒子同时处于所有可能状态的叠加中。」

拆解：

```
P:   测量者/接收侧（带时间戳：测量行为）
ΔV:  波函数（未分化的概率幅；在测量之前，属性未被定义）
J:   测量结果（落地为可复现的实验读数）
────────────────────────────
锚:
  硬锚:    量子态层析（物理事实：同一制备、多基多次投影，
           统计重构全貌）；干涉实验可复现
  押金类比: 「叠加」= 测量前属性未定义，不是同时具备一切属性
  软锚:    无
证据层:    物理历史（教科书与实验可查）
勘误:      #1 见下
────────────────────────────
```

**勘误 #1：叠加不是「同时是 A、B、C」**

原断言（常见误读）：叠加态 = 一个东西同时是圆、正方体、三角形。

判定：把「属性未被定义」误解成「同时具备所有确定属性」。这不是叠加态，这是把叠加态误解成了「同时是」。

修正：**叠加态 = 在测量之前，那些属性根本没有被定义。** 你问它是不是 A，它给一个概率；你问它是不是 B，它给另一个概率；但你问之前，它没有那些属性。值不是它自己的属性，而是「和哪些变量一起被问」的函数（Kochen–Specker 语境性）。

这条编译是「不可说」的物理版，也是「不预付」的精确表述：**没被问的题没有答案。**

## 编译对象 2：测量

**方言原句**：「测量改变了系统。」

拆解：

```
P:   测量者（带时间戳：测量行为；注意：P 本身也是量子系统）
ΔV:  测量装置与系统的耦合（过手的势能差）
J:   测量结果（落地；由测量创造，不是预先存在）
────────────────────────────
锚:
  硬锚:    贝尔不等式实验（2015 无漏洞，2022 诺奖）——
           J 不预先存在
  押金类比: 「测量创造结果」= 交接创造 J
  软锚:    无
证据层:    物理历史（实验可查）
勘误:      #2 见下
────────────────────────────
```

**勘误 #2：测量公理不适用于经典模式**

原断言（过度推广）：一切 J 都由测量创造。

判定：把量子模式的口径无条件搬到经典模式。经典域里 J 预先存在，测量是读取——工程全建在这一条上，一寸不能动。

修正：**双模式并存。** 经典模式：P → ΔV → J，J 预先存在，测量是读取。量子模式：P → ΔV（叠加）→ 测量 → J，J 由测量创造。切换条件由对易结构决定（联合表是否装得下所有变量），不依赖「是否叠加」这种基相关的软词。

## 编译对象 3：贝尔不等式

**方言原句**：「量子纠缠超越经典极限。」

拆解：

```
P:   纠缠对的两个测量端（各自带时间戳）
ΔV:  测量设置（A/A'、B/B' 各为 ±1 的选项）
J:   关联值（落地为实验读数的组合）
────────────────────────────
锚:
  硬锚:    CHSH 经典上限 2；量子上限 2√2（Tsirelson 界，
           1980）；PR 盒 4（数学自洽，自然界未造）；
           2015 无漏洞实验三家越过 2，与 2√2 相容
           （首批约 2.4±0.2，理想 2.828；一家报 11.5σ，
           尾概率 3.74×10⁻³¹）；2022 诺贝尔物理学奖
  押金类比: 无（本节全部是硬锚）
  软锚:    无
证据层:    物理历史（教科书与实验档案可查）
勘误:      #3、#4 见下
────────────────────────────
```

**勘误 #3：2 是记账恒等式，不是强度上限**

原断言（早期误读）：2 是相关强度的天花板，量子突破了这个上限。

判定：2 不封任何单个关联。经典答题卡在单独一对设置上能给到 ±1——比量子给的还强。2 封的是四个关联的一种组合。

修正：**2 是「四个反事实答案同时存在」的记账恒等式。** 经典答题卡上 A、A′、B、B′ 各为 ±1，代入 S = AB − AB′ + A′B + A′B′，十六张卡结果恒为 ±2。破 2 的精确含义：任何联合分布表都装不下这四个边际。量子获胜不靠数字变大，靠的是**不再为没问的问题预付答案**。

**勘误 #4：负号买到的是对称性，不是零**

原断言（比喻冒充因果）：负号 → 相减 → 产零 → 破 2。

判定：破 2 的每一步里没有任何一个数变大。超的不是强度，是组合。

修正：负号真正的工位是选中总自旋为零的状态。总自旋为零 → 转动不变 → 关联只能是夹角的函数 → 自旋代数把它定成 −cos θ。**负号买到的是对称性，不是零。**

**2√2 的出生地**：经典答题卡上 (B−B′) 和 (B+B′) 全有或全无：一个归零，一个 ±2。量子中 B 和 B′ 是不对易算符（夹角 90° 时反对易），两个组合数各自为 √2。预算被均分，永远不归零也不归二。均分这一步就是 √2 的出生地。顺着算符界走到底，天花板是 2√2。

## 编译对象 4：π 的超越性

**方言原句**：「π 是无限不循环的。」

拆解：

```
P:   计算者/接收侧（带时间戳：某一次计算行为）
ΔV:  圆的几何约束（圆周与直径之比——定义在）
J:   π 的某一位（落地为可复现的数值）
────────────────────────────
锚:
  硬锚:    π 定义在（圆周与直径之比）；无理（Lambert,
           1761）；超越（Lindemann, 1882）；BBP 算法
           （1995，直接取第 N 位，不需从头算起）
  押金类比: 无（本节全部是硬锚）
  软锚:    无
证据层:    物理历史（教科书可查）
勘误:      #5 见下
────────────────────────────
```

**勘误 #5：无限不循环还不是超越**

原断言（常见误读）：π 超越 = 无限不循环。

判定：锚层低了半格。无限不循环是无理层的性质——√2 也无限不循环，却是代数数（x²=2 钉死）。超越层的独有性质未被用到。

修正：**π 三层身份分层锚定。** 定义在（圆周与直径之比）；无理（Lambert 1761，无限不循环）；超越（Lindemann 1882，没有任何有限公式能捕获它）。**定义在，所以每一位都算得出、都可信；写不完，所以永远没有最后一位。**

**π 与 PEF 的对齐**：π 的下一位在被算出来之前已经定了；你的下一笔在被写出来之前还不是任何东西。π 站在结果侧（每个闭环都吐出同一个签名）；心/源站在生成侧。**π 是展开的模型，不是本体的隐喻——把它提升到「源」，和把它提升到「自我」，是同一个作废的公证。**

## 本篇出处卡

1. 贝尔 1964；CHSH 1969。经典上限 2 为记账恒等式（四个反事实答案同时存在的恒等式），非相关强度上限。
2. 量子预言 2√2（Tsirelson 界，1980）；PR 盒 4（数学自洽，自然界未造）。
3. 2015 无漏洞实验三家（Delft、NIST、Vienna）越过 2，与 2√2 相容——首批约 2.4±0.2，理想预言 2.828；其中一家报 11.5 个标准差，尾概率 3.74×10⁻³¹。2022 年诺贝尔物理学奖：Aspect、Clauser、Zeilinger。
4. 叠加态 ≠ 同时具备一切确定属性（测量前属性未定义）；坍缩后仍为纯态，冯·诺依曼熵为零——熵增住退相干，不住坍缩。
5. Kochen–Specker 1967；GHZ 1989（Bouwmeester、潘建伟等，Nature 2000）。语境性：值是问题的函数。
6. π 三层身份：定义在（圆周与直径之比）；无理（Lambert，1761）；超越（Lindemann，1882）。BBP 算法（1995）为十六进制第 N 位提取。√2 为反例证人：无理、无限不循环、x²=2 钉死、代数数——且 Tsirelson 界 2√2 正是两个 √2 撑起的。
7. 「π 与心的严格分层」见 pef-philosophy 第九篇《源，与它的名字》及其勘误卡；本卷 π 段与彼分层一致。
8. 本节全部为物理历史事实，可查证。框架内映射（如「源 = 生成侧」）按出处卡 6 的纪律标注，不混入物理断言。

## 本篇死亡条款

当以下情况发生，本篇失效：

- 出现可独立复现的实验，证明存在超越贝尔不等式上限（2√2）且仍物理可实现的相关——推翻 Tsirelson 界的普适性（PR 盒若被自然界实现）；
- 证明 π 不是超越数（推翻 Lindemann 1882——这需要一项推翻整个超越数理论的数学工作）；
- 证明存在一个「预写剧本」模型可复现量子关联（推翻贝尔实验结论）。

这三条都是可检验的。检验不到，本篇就是一份可反驳的编译草稿；检验到了，本篇进勘误，不撤稿。
