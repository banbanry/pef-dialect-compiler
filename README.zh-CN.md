# PEF 方言编译器

把哲学方言、概念与「不可说」，编译到 PEF 公共语法。

**PEF 公共语法（一行）：**
任何交接都可以写成 `P + ΔV → J` —— 一个带时间戳的主体，一个以势能差抵达接收侧的变量，一个落地的结果；外加三条错误处理规则：**不可自证、必须外部锚定、允许局部失败（且留审计链）**。

**这个编译器做什么：**
哲学、宗教、工程、AI 架构各自成一套方言。每套方言里都有「不可说」——前人把脚手架拆掉了，后人只能背概念。本编译器尝试把这些概念重新拆开，装回 `P + ΔV → J` 的公共语法上，让任何一套方言的断言都能被：拆解、锚定、审计、反驳。

**这个编译器不做什么：**
不传教。不宣称找到终极答案。不把「不可说」说成「可说完」。它只做一件事：把每一句断言放回交接结构里，标出它的锚，记下它的勘误。

## 编译产物长什么样

每个编译对象产出一份编译报告：

```
方言原句      （原文，一字不改）
─────────────
主体 P        （谁在交接？时间戳？）
变量 ΔV       （传的是什么？从产生岸看是内容，从接收岸看是势能差）
结果 J        （落在哪里？）
─────────────
锚            （哪些可复现？数学/实验/物理不变量 = 硬锚；不可复现 = 软锚，标注）
证据层        （框架内事实 / 物理历史事实 / 工程观察，三层分级）
勘误          （原断言 → 判定 → 修正，只追加不涂改）
```

## 快速开始

```bash
# 编译一段方言文本（UTF-8 文件）
python scripts/pef_compile.py compile --input 方言.txt

# 指定方言 + 固定 π 锚序号（可复现）
python scripts/pef_compile.py compile --input 方言.txt --source-dialect daojia --seq 7 --out out.json

# 列方言注册表（道家/佛学/量子/AI架构）
python scripts/pef_compile.py dialects
```

输出为三段 JSON（`schema: pef-phi-1.0`）：

```json
{
  "compiled": { "source_dialect": "daojia", "pi_anchor": "π-7-6", "claims": [...], "terms_normalized": {...} },
  "dialect":  { "matched": "daojia", "signals_hit": [...] },
  "audit":    { "rho_residual": 1.0, "rho_unanchored": 1.0, "rho_unmapped_auto": 1.0, "hash": "...", "ts": "..." }
}
```

### 脚本诚实边界

- **自动（可信）**：方言识别、承诺分级、锚检测（硬锚/押金/软锚）、π 锚分配、术语归一、残留率 ρ'。
- **半自动（需人工）**：结构映射只给候选槽，装不满标 `UNMAPPED(需人工编译)`——三槽拆解是语义判断，脚本不假装全自动。
- **ρ' 主指标** = 无锚断言占比，即「边界厚度」：ρ' 高 = 这段方言不可说多；ρ' 低 = 已经说尽。ρ' = 0 且每句都有硬锚，才可入结构库。

## 编译步骤（六步）

1. **收原句**：原样保留输入。只追加，不涂改。
2. **拆主体 P**：谁在交接？有没有时间戳？没有时间戳的「永恒主体」标记为 `P?`，是拆解对象不是拆解工具。
3. **找变量 ΔV**：过手的是什么？从产生岸看是内容，从接收岸看是势能差。检查是否有「没被问就存在」的预写变量（贝尔判据）。
4. **定结果 J**：落在接收侧。J 是落地的不是生成的；「生成/创造」出现在结果位是范畴错置。
5. **标锚**：硬锚（可独立复现：π、kT·ln2、实验数据、档案）/ 带押金的类比（有可操作后果）/ 软锚（只在说话者心里，仅作钩子文本，不进结构）。
6. **记勘误**：原断言 → 判定 → 修正，只追加。

## 证据三档

| 层 | 内容 | 验证方式 |
|---|---|---|
| 框架内事实 | 本编译器自身的术语与推导 | 查本仓库文档 |
| 物理与历史事实 | π、贝尔不等式、热力学、史实 | 教科书 / 原始档案可查 |
| 工程观察 | 系统行为、经验数据 | 仅作为线索，不作定论 |

## 验证方式

每个编译产物可被独立核验：

- 锚：读者可自行查教科书 / 档案复现；
- 勘误：只追加不涂改，历史保留；
- 反驳：任何人对任何一步「拆法」有异议，可按语法规范重新拆，不涉及权威。
