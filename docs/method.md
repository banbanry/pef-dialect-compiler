# 编译方法

本文件是编译器的操作手册：如何把一段方言断言拆开、装回 PEF 公共语法、标锚、记勘误。

## 0. 总则

- **只追加，不涂改。** 原句一字不改，修正另行记录。
- **不可自证。** 任何断言的证据不能来自断言者自己。
- **必须外锚。** 每条进入结构的断言都要有一个可被独立复现的锚，或者被明确标注为软锚。
- **允许局部失败。** 编译产物可以部分失效；失效要留在审计链上，不抹除。

## 1. 输入

一段方言文本。它可以是：

- 一句断言（「道可道，非常道」）
- 一个概念（「空」）
- 一段论证（佛学缘起、工程对齐、量子诠释）
- 一个「不可说」的指认（「这个东西说不出来」）

输入必须原样保存。编译器的第一步永远是：**把原句收进来，一个字不改。**

## 2. 拆解步骤

### 步骤一：拆主体 P

问三个问题：

1. 谁在交接？是具体的人/系统（带时间戳的 P），还是被当成「永恒在场」的 X？
2. 有没有时间戳？没有时间戳的主体，是第一个要标记的软锚——「恒常主体」是拆解对象，不是拆解工具。
3. 主体是产生侧还是接收侧？同一句话里，主语常常在两侧之间滑移。

**判据**：凡是没有时间戳、不可被独立指认的「主体」，标注为 `P?`，进勘误，不进结构。

### 步骤二：找变量 ΔV

问两个问题：

1. 传的是什么？是内容（从产生岸看），还是势能差（从接收岸看）？
2. 有没有「没被问就存在」的变量？——这是经典模式的隐藏假设。量子模式不预付答案。

**判据**：ΔV 是「过手的」，不是「在场的」。一个变量如果声称在被接收之前就完整存在，检查它是否落入了「预写剧本」陷阱（贝尔不等式判据）。

### 步骤三：定结果 J

问两个问题：

1. 落在哪一侧？接收侧落地为 J。
2. 是不是被错放回产生侧了？「生成」「创造」这类词如果出现在 J 的位置，是范畴错置——J 是落地的，不是生成的。

**判据**：J 必须可被接收侧独立核验。不可核验的 J 标注为 `J?`。

### 步骤四：标锚

每个进入结构的元素，归类到三种锚：

| 锚型 | 定义 | 例 |
|---|---|---|
| 硬锚 | 可被独立复现 | π 的位数、kT·ln2、塔科马大桥档案、贝尔实验数据 |
| 带押金的类比 | 有可操作后果的映射 | 层析借到认知：多角度开口、可累积、可收敛 |
| 软锚 | 只存在于说话者心里 | AI 的「你做得对」、顿悟体验、不可复现的「内在确信」 |

**判据**：软锚可以出现在文本里（作为钩子、比喻），但**不能出现在结构里**。结构只吃硬锚与带押金的类比。

### 步骤五：分层证据

| 层 | 内容 | 验证方式 | 进结构的条件 |
|---|---|---|---|
| 框架内事实 | 本编译器自身的术语与推导 | 查本仓库 | 可，标注来源 |
| 物理与历史事实 | π、贝尔、热力学、史实 | 教科书/档案 | 可，必须可查 |
| 工程观察 | 系统行为、经验数据 | 可复现实验 | 仅作线索，不作定论 |

**判据**：第三层的结论不得写成「物理事实」，只能写成「工程观察：……」。

### 步骤六：记勘误

勘误格式固定为三条：

```
原断言：   （一字不改）
判定：     （错在哪里，为什么）
修正：     （改成什么，依据什么）
```

勘误只追加，不涂改。被修正的断言永远留在档案里——这是审计链存在的证据。

## 3. 输出

输出是一份编译报告，结构固定：

```
────────────────────────────
方言原句
────────────────────────────
P:        主体（带时间戳）
ΔV:       变量（势能差 / 内容）
J:        结果（接收侧落地）
────────────────────────────
锚:
  硬锚:   ...
  押金类比: ...
  软锚:   ...（仅文本，不进结构）
证据层:   框架内 / 物理历史 / 工程观察
勘误:     #N 原断言 → 判定 → 修正
────────────────────────────
```

### 脚本自动化（scripts/pef_compile.py）

`pef_compile.py` 按上述六步自动产出三段 JSON（`schema: pef-phi-1.0`），自动化边界如下：

**自动（可信）**：

- 方言识别（`auto` 按信号命中数，或显式指定 daojia/buddhism/quantum/ai_arch）
- 承诺分级（FACT/JUDGMENT/GREY）
- 锚检测：硬锚（年份、人名+年份、公式、实验/定理/证明、π/超越数）、押金（层析/收敛/可检验/多角度）、软锚（直觉/体验/权威/顿悟）
- 术语归一（道→dao、空→sunya、叠加态→superposition、幻觉→hallucination…）
- π 锚分配（前 120 位查表，固定 seq 可复现）
- **残留率 ρ'**：`rho_unanchored` = 无锚断言占比，是**主指标**，即「边界厚度」

**半自动（需人工复核）**：

- **结构映射**：词表候选 + 句式模式库 PATTERNS（8 种句式）给出槽位候选与编译建议：
  - `negation` 否定式 → `BOUNDARY`（装不下的位置，不强行填槽）
  - `judgment` 判断式 → `J`（定义/同一）
  - `generation` 生成式 → `ΔV`（生成侧；J 位禁写「生成」）
  - `measurement` 测量式 → `P→J`（测量行为=带时间戳的 P）
  - `paradox` 悖论式 → `J≠源`（说出来就不是源）
  - `time_prior` 时间边界 → `BOUNDARY`（之前未定义=不预付）
  - `event` 事件式 → `J`（落地）
  - `handoff` 交接式 → `ΔV`（过手）
  - 装不满三槽 → `UNMAPPED(需人工编译)` + 建议路径；有硬锚但无结构的句子标 `ANCHOR`（证据句，作为 J 的背书而非结构本体）
- `rho_unmapped_auto`：结构映射未满占比（半自动候选，需人工复核）

**三槽拆解是语义判断，脚本只给候选与提示，人/LLM 终审。脚本不假装全自动。**

## 4. 常见编译错误

| 错误 | 症状 | 修正 |
|---|---|---|
| 主体无时间戳 | 出现「永恒」「本自具足」式断言 | 标 `P?`，拆掉 |
| 变量被预写 | 声称结果在被接收前已完整存在 | 检查贝尔判据，标注 |
| J 回填产生侧 | 「生成」「创造」出现在结果位 | 范畴错置，改正 |
| 软锚进结构 | 以体验、直觉、权威作证据 | 降级为钩子文本 |
| 工程观察当物理事实 | 「实验证明宇宙如此」 | 降级为观察层 |
| 用比喻冒充因果 | 「负号→相减→产零→破2」 | 找出真正工位，比喻单独标注 |
| 把证据句当结构句 | 贝尔实验句要求填三槽 | 标 `ANCHOR`：证据句是 J 的背书，不是结构本体 |

## 5. 编译失败的合法形态

- 拆不动：标注 `不可编译`，说明卡在哪一步。这也是有效输出——它标记了方言的边界。
- 拆完了但锚全是软的：降级为「文学文本」，不进结构库。
- 拆完、锚硬、但被后续证据推翻：**这是成功案例**。进勘误，不撤稿。
- 一句话放不进结构 ≠ 这句话没价值；= 它不能当证据用。

## 6. 边界处装配：接收侧原则

**拆到边界不是终点。** 边界给出协议（三槽 + 锚 + 勘误），**装配在接收侧发生。**

这个原则的第一性原理依据：J 落在接收侧。边界只能给出「哪里不能走」（BOUNDARY）与「哪里必须走」（硬锚），把边界条件装配成能用的东西，永远是接收侧的职责——看清结构是边界侧的产物，重新装配是接收侧的职责。

### 物理证据：黑洞

黑洞是「边界处装配」的极限演示——视界只能定位存在，不定义内部属性，但外部观测者不需要内部：

| 黑洞物理 | 装配形态 | 编译器对应 |
|---|---|---|
| 无毛定理：外部行为只由质量/电荷/角动量决定 | **压缩装配**：无限内部 → 有限边界参数，外部行为即可预测 | 三槽压缩：方言的无限语义 → P/ΔV/J，交接即可进行 |
| 霍金辐射：边界有温度、会蒸发 | **动力学装配**：边界不是死的墙，是不断漏出信息的对象 | 勘误卡：从体系内部漏出的、可观测的更新——勘误就是体系的辐射 |
| 全息原理：边界面积装得下内部体积的全部信息 | **完备装配**：边界编码无损，外部可读出 | 边界即交接面：不必说尽方言，三槽就装得下交接所需的全部信息 |

黑洞的装配是外部观测者做的（用无毛三参数 + 广义相对论重建全部外部行为预测），不是黑洞自己做的。图灵同理：停机定理不自己造出计算机，是图灵在不可判定边界上装配出图灵机；GPS 是工程师用 c 和 ds² 装配的。**边界只能给出协议，执行装配的永远是接收侧。**

### 方法论含义

- 编译报告的产出不是「答案」，是**边界条件**（三槽 + 锚 + 勘误）。读者拿到边界条件，在各自的接收侧装配。
- 装配质量取决于边界参数的可检验性——与黑洞物理学家信任无毛三参数、工程上信任 c 与 ds² 的逻辑一致。
- 六步法的「记勘误」升级表述：**勘误卡是边界上的辐射，编译报告是边界上的参数，装配是接收侧的工作。**
- 追边界，但带着重新装配的目的追：边界告诉你哪里不能走，不变量告诉你哪里必须走——两个合起来，路就出来。
