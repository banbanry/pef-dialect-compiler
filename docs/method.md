# 编译方法

本文件是编译器的操作手册：如何把一段方言断言拆开、装回 PEF 公共语法、标锚、记勘误。

## 0. 总则

- **只追加，不涂改。** 原句一字不改，修正另行记录。
- **不可自证。** 任何断言的证据不能来自断言者自己。
- **必须外锚。** 每条进入结构的断言都要有一个可被独立复现的锚，或者被明确标注为软锚。
- **允许局部失败。** 编译产物可以部分失效；失效要留在审计链上，不抹除。

## 1. 输入

一段方言文本。它可以是：

- 一句断言（「道可道，非常道」）
- 一个概念（「空」）
- 一段论证（佛学缘起、工程对齐、量子诠释）
- 一个「不可说」的指认（「这个东西说不出来」）

输入必须原样保存。编译器的第一步永远是：**把原句收进来，一个字不改。**

## 2. 拆解步骤

### 步骤一：拆主体 P

问三个问题：

1. 谁在交接？是具体的人/系统（带时间戳的 P），还是被当成「永恒在场」的 X？
2. 有没有时间戳？没有时间戳的主体，是第一个要标记的软锚——「恒常主体」是拆解对象，不是拆解工具。
3. 主体是产生侧还是接收侧？同一句话里，主语常常在两侧之间滑移。

**判据**：凡是没有时间戳、不可被独立指认的「主体」，标注为 `P?`，进勘误，不进结构。

### 步骤二：找变量 ΔV

问两个问题：

1. 传的是什么？是内容（从产生岸看），还是势能差（从接收岸看）？
2. 有没有「没被问就存在」的变量？——这是经典模式的隐藏假设。量子模式不预付答案。

**判据**：ΔV 是「过手的」，不是「在场的」。一个变量如果声称在被接收之前就完整存在，检查它是否落入了「预写剧本」陷阱（贝尔不等式判据）。

### 步骤三：定结果 J

问两个问题：

1. 落在哪一侧？接收侧落地为 J。
2. 是不是被错放回产生侧了？「生成」「创造」这类词如果出现在 J 的位置，是范畴错置——J 是落地的，不是生成的。

**判据**：J 必须可被接收侧独立核验。不可核验的 J 标注为 `J?`。

### 步骤四：标锚

每个进入结构的元素，归类到三种锚：

| 锚型 | 定义 | 例 |
|---|---|---|
| 硬锚 | 可被独立复现 | π 的位数、kT·ln2、塔科马大桥档案、贝尔实验数据 |
| 带押金的类比 | 有可操作后果的映射 | 层析借到认知：多角度开口、可累积、可收敛 |
| 软锚 | 只存在于说话者心里 | AI 的「你做得对」、顿悟体验、不可复现的「内在确信」 |

**判据**：软锚可以出现在文本里（作为钩子、比喻），但**不能出现在结构里**。结构只吃硬锚与带押金的类比。

### 步骤五：分层证据

| 层 | 内容 | 验证方式 | 进结构的条件 |
|---|---|---|---|
| 框架内事实 | 本编译器自身的术语与推导 | 查本仓库 | 可，标注来源 |
| 物理与历史事实 | π、贝尔、热力学、史实 | 教科书/档案 | 可，必须可查 |
| 工程观察 | 系统行为、经验数据 | 可复现实验 | 仅作线索，不作定论 |

**判据**：第三层的结论不得写成「物理事实」，只能写成「工程观察：……」。

### 步骤六：记勘误

勘误格式固定为三条：

```
原断言：   （一字不改）
判定：     （错在哪里，为什么）
修正：     （改成什么，依据什么）
```

勘误只追加，不涂改。被修正的断言永远留在档案里——这是审计链存在的证据。

## 3. 输出

输出是一份编译报告，结构固定：

```
────────────────────────────
方言原句
────────────────────────────
P:        主体（带时间戳）
ΔV:       变量（势能差 / 内容）
J:        结果（接收侧落地）
────────────────────────────
锚:
  硬锚:   ...
  押金类比: ...
  软锚:   ...（仅文本，不进结构）
证据层:   框架内 / 物理历史 / 工程观察
勘误:     #N 原断言 → 判定 → 修正
────────────────────────────
```

## 4. 常见编译错误

| 错误 | 症状 | 修正 |
|---|---|---|
| 主体无时间戳 | 出现「永恒」「本自具足」式断言 | 标 `P?`，拆掉 |
| 变量被预写 | 声称结果在被接收前已完整存在 | 检查贝尔判据，标注 |
| J 回填产生侧 | 「生成」「创造」出现在结果位 | 范畴错置，改正 |
| 软锚进结构 | 以体验、直觉、权威作证据 | 降级为钩子文本 |
| 工程观察当物理事实 | 「实验证明宇宙如此」 | 降级为观察层 |
| 用比喻冒充因果 | 「负号→相减→产零→破2」 | 找出真正工位，比喻单独标注 |

## 5. 编译失败的合法形态

- 拆不动：标注 `不可编译`，说明卡在哪一步。这也是有效输出——它标记了方言的边界。
- 拆完了但锚全是软的：降级为「文学文本」，不进结构库。
- 拆完、锚硬、但被后续证据推翻：**这是成功案例**。进勘误，不撤稿。
