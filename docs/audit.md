# 审计纪律

编译器的一切产物遵守此纪律。这是「编译器可信」的根据——不是作者权威，是可复现的审计记录。

## 1. 只追加，不涂改

- 方言原句一字不改。
- 勘误只追加：原断言永远保留，判定与修正另行记录。
- 版本只增不减：被推翻的编译产物不撤稿，进勘误。

## 2. 出处卡

每个编译对象必须带出处卡，记录：

- 每个锚的出处（定理、实验、档案、教科书条目）
- 类比与映射的边界（前端有锚、后端是否定论）
- 「作者方言」的声明（哪些句子是框架内部术语，非通用含义）

出处卡不持正文立场。它只记录：这句断言在什么锚上站着。

## 3. 勘误卡

勘误卡格式：

```
勘误 #N：原断言标题
原断言：  （一字不改）
判定：    （错在哪里）
修正：    （改成什么，依据）
```

勘误来源必须注明（自我修正 / 外部审计）。被修正的断言按「只追加」原则保留在案。

## 4. 三审制

大型编译对象（整篇文章级）应经历：

1. **一审**：拆解是否成立（P/ΔV/J 是否放对位置）
2. **二审**：锚是否真的硬（能否被独立复现）
3. **三审**：勘误是否完整（是否留了反例）

三审结论记录在定稿记中。定稿记发布时删去，但档案保留。

## 5. 硬性边界

| 边界 | 处理 |
|---|---|
| 物理事实与类比 | 物理层有锚；认知映射层为带押金的类比，卡内不背书 |
| 工程观察与物理事实 | 观察层结论不得写成物理事实 |
| 软锚 | 只作钩子文本，不进结构 |
| 「不可说」 | 只承认单次说不完，不承认算不出来 |
| 死亡条款 | 每个编译对象预写自己的失败方式 |
