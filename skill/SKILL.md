# PEF 方言编译器

## 边界

- **做**：把一段方言断言拆解成 P/ΔV/J，标锚，分层证据，记勘误。
- **不做**：不裁决哪个哲学体系正确；不把「不可说」宣称说完了；不用软锚（体验、权威、直觉）当结构证据。
- **输入**：一段原文（一字不改保留）。可以是单句、概念、段落、整套术语。
- **输出**：结构化编译报告（见下方模板）。

## 编译步骤（六步）

1. **收原句**：原样保留输入。只追加，不涂改。
2. **拆主体 P**：谁在交接？有没有时间戳？没有时间戳的「永恒主体」标记为 `P?`，是拆解对象不是拆解工具。
3. **找变量 ΔV**：过手的是什么？从产生岸看是内容，从接收岸看是势能差。检查是否有「没被问就存在」的预写变量（贝尔判据）。
4. **定结果 J**：落在接收侧。J 是落地的不是生成的；「生成/创造」出现在结果位是范畴错置。
5. **标锚**：硬锚（可独立复现：π、kT·ln2、实验数据、档案）/ 带押金的类比（有可操作后果）/ 软锚（只在说话者心里，仅作钩子文本，不进结构）。
6. **记勘误**：原断言 → 判定 → 修正，只追加。

## 输出模板

```
────────────────────────────
方言原句
────────────────────────────
P:        主体（带时间戳）
ΔV:       变量（势能差 / 内容）
J:        结果（接收侧落地）
────────────────────────────
锚:
  硬锚:   ...
  押金类比: ...
  软锚:   ...（仅文本，不进结构）
证据层:   框架内 / 物理历史 / 工程观察
勘误:     #N 原断言 → 判定 → 修正
────────────────────────────
```

## 证据三档

| 层 | 内容 | 进结构条件 |
|---|---|---|
| 框架内事实 | 本体系术语与推导 | 可，标注来源 |
| 物理与历史事实 | 教科书可查 | 可，必须可查 |
| 工程观察 | 经验数据 | 仅线索，不作定论 |

## 常见编译错误（必须主动检查）

- 主体无时间戳（`P?`）
- 变量被预写（结果在被接收前已完整存在）
- J 回填产生侧（「生成」出现在结果位）
- 软锚进结构（以体验/直觉/权威为证据）
- 工程观察写成物理事实
- 用比喻冒充因果

## 编译失败的合法形态

- 拆不动 → 标注「不可编译」及卡点（这是方言边界的有效标记）
- 锚全软 → 降级为文学文本，不进结构库
- 锚硬但被推翻 → 成功案例，进勘误不撤稿
